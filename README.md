# 엑셈 기업탐방을 갔다오고 나서 해보고싶어진 개인 프로젝트
---
## 프로젝트 연대기  
시작 : 4월 23일 / 초기에는 버튼으로 스캔을 하는 형식

4월 27일 : 서버(간단한 DB sqlite, fastapi로 서버 오픈) 및 간단한 어플 제작 (회원가입, 로그인, 스캔화면)  
간단하게 데이터 주고받는거 구현  

4월 28일 : 핸드폰 어플 중 main에서만 서버를 연결하는 문제 -> 싱글톤으로 그냥 서버 인스턴스를 만들어버림 -> 필요한곳에서 서버를 호출하면 거기서 연결하도록  
자동로그인 버튼 구현 -> 버튼을 체크후 로그인하면 앱을 껏다켜도 로그인되어있는 상태  
테스트할때마다 서버 도메인이 바뀌는 것을 방지하기위해서 ngrok으로 도메인 고정  
서버에서 필요한 DB 추가  

4월 29일 : 로그인 시 비콘스캔 자동으로 변경 -> 자동으로 스캔하다보니 출석이 되자마자 퇴실이 되어버리는 현상이 나타남  
출석 후 시간을 정해서 그 시간이 지나야지만 다시 스캔이 되도록 변경  
앱에서 서버로 Log를 보내는데 같은 함수가 많이 쓰이는것을 발견 -> 로그데이터를 만드는 함수를 하나의 함수로 정의함  
자동 스캔으로 생기는 잔 버그들 때문에 고민 -> 출석이든 퇴실이든 스캔이 한번 되고나면 스캔이 꺼졌으면 좋겠는데 계속켜져있었음  
-> 스캔이 되면 자동으로 스캔이 끄도록하고 -> 시간이 지나면 자동으로 스캔을 켜지도록 수정 (시간으로 출석과 퇴실을 구분하도록 해놨음)   

5월 2일 : 시간으로 출석과 퇴실을 변경하는것은 아니다고 생각하여서 서버에 새로운 DB를 추가하고 그 유저가 출석(1) 퇴실(0)로 구분하도록 설정 ->  
그에 맞춰서 앱도 데이터추가하고 변경 -> 이제 상태관리는 서버에서 시간관리는 앱에서 하도록 변경되었음 -> 효율적임 

5월 3일 : 대시보드 구현 -> 1~29자리가 있고 자리에 회원가입되면 그 사람의 출석 정보가 나타남, 관리자모드 on/off구현

5월 6일 : 관리자 모드에 들어가면 회원들의 정보를 볼 수 있음 / 모달로 회원 정보를 나타내도록 표시 / 관리자모드로 좌석을 변경 및 스왑 할 수 있는 기능, 회원 삭제 기능 추가

5월 7일 : 좌석번호가 1~29 이외에 값이 입력되던 버그 수정 / 
퇴실시간 전에 퇴실하려고 하면 한 번 되묻는 창 띄우기 -> 서버로 퇴실시간을 관리하고 앱에서는 서버에 요청해서 퇴실시간을 받는 식으로 구현 -> 퇴실시간이 바뀔때마다 앱을 다시 업데이트 할 필요없이 서버만 수정하면 됨
서버에서 계속해서 값이 바뀌어도 앱의 코드는 변경안해도 되도록 입실,퇴실시간 총 좌석수를 설정 

5월 8일 : 관리자로그인 이후에 좌석배치를 동적으로 변경할 수 있도록 설정 + 오늘 출석했는가를 확인할 수 있는 변수를 추가하고 서버에서 하루가 지나면 그값을 초기화 시킬 수 있게 설정 (apscheduler)

5월 10일 : 행위 횟수를 다루는 테이블 추가 스케쥴러로 작동되는 오늘출석확인 리셋 함수에 결석횟수만 업데이트 하게 하고 나머지는 앱을 통해서 해당 행위를하면 값이 증가하도록 설정  
정상 입실 -> 정상 퇴실 (출석)  
정상 입실 -> 비정상 퇴실(일찍 퇴실) (조퇴)  
비정상 입실(늦게 입실) -> 정상 퇴실 (지각)  
오늘 출석했다는 값이 0이면 -> 결석  

5월 11일 : 오류 수정
